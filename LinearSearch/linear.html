Linear Search

function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) {
      return i;
    }
  }
  return -1;
}

About Linear Search

Linear Search checks each element in the array sequentially until the target is found or the end of the array is reached. It works on both sorted and unsorted arrays.
