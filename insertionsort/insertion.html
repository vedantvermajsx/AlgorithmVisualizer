Insertion Sort

for (let i = 1; i < n; i++) {
  let key = arr[i];
  let j = i - 1;
  while (j >= 0 && arr[j] > key) {
    arr[j + 1] = arr[j];
    j--;
  }
  arr[j + 1] = key;
}

About Insertion Sort

Insertion Sort builds a sorted array one element at a time by taking each element and inserting it into its correct position within the already-sorted portion of the array.

Complexity
